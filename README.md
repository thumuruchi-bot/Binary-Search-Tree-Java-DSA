# Binary Search Tree - Java DSA

## Author

T. Ruchitha

## Description

This program implements a Binary Search Tree in Java. It allows elements to be inserted into the tree, searched, and displayed using inorder traversal.

## Technology

- Java
- Data Structures
- Algorithms
- Binary Search Tree
- Recursion

## Algorithm

Binary Search Tree

## File Name

BinarySearchTree.java

## Input

Insert: 50 30 70 20 40 60 80
Search: 60

## Output

Inorder Traversal:
20 30 40 50 60 70 80

Element 60 found

## Time Complexity

Average Case: O(log n)
Worst Case: O(n)

## Space Complexity

O(n)
